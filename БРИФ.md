## 1. Осталось: публикация

Репозиторий вы уже переименовали в `hr-gastronomia` — этот шаг закрыт.

**Но есть препятствие: репозиторий приватный, а GitHub Pages на бесплатном тарифе
работает только с публичными.** Пока он приватный, сайт не опубликуется никак.

- [ ] **Сделать репозиторий публичным**: Settings → в самом низу, блок *Danger Zone* →
      *Change repository visibility* → **Change to public**.
- [ ] **Включить Pages**: Settings → Pages → *Deploy from a branch* → ветка
      `claude/oxana-personal-landing-e7uvxk`, папка `/ (root)` → Save.

После этого сайт откроется по адресу `https://oxana-arg.github.io/hr-gastronomia/`.

Что станет видно посторонним, если сделать репозиторий публичным: ровно то же, что
и так будет на сайте — тексты, цены, фотографии, ник в Telegram. Единственное
исключение — этот файл, `БРИФ.md`: в нём внутренняя кухня, логика ценообразования
и незакрытые вопросы. Скажите, и я его удалю из репозитория перед публикацией,
а список вопросов перенесу в переписку.
