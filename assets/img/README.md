## Как заменить фотографию

Загрузите новый файл **с тем же именем** — репозиторий → папка `assets/img` →
**Add file** → **Upload files** → **Commit changes**. Через минуту сайт обновится.
Править код не нужно.

Пропорции подгонять тоже не надо: рамки имеют фиксированную форму, снимок обрезается
по центру. Портреты встают в вертикальную арку 4:5, кадры в фотополосе — в квадрат.
Проверьте только, что главное на снимке не у самого края.

Перед загрузкой сожмите файл через [Squoosh](https://squoosh.app): ширина до 1600 px,
JPEG, качество 75–80, примерно 150–300 КБ. Иначе страница будет открываться медленно.

## Служебные файлы

- `og-cover.svg` — картинка при отправке ссылки в мессенджер. Готова.
- `favicon.svg` — иконка вкладки браузера. Готова.
- `*.svg` с подписями — страховочные заглушки. Не удаляйте: если какое-то фото
  однажды не загрузится, вместо пустого места покажется аккуратная заглушка.
