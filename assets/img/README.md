# Фотографии

Нужны **четыре файла**. Пока их нет, на странице показываются пастельные заглушки —
сайт выглядит цельно, но фото, конечно, лучше.

## Что куда загрузить

Имена должны совпадать буква в букву, расширение — `.jpg`:

| Имя файла | Какое фото | Где на странице |
|---|---|---|
| `oksana.jpg` | Вы в бежевом жакете | первый экран, справа |
| `kitchen-plating.jpg` | Повар собирает блюдо | блок «Давайте познакомимся?» |
| `bar-duo.jpg` | Двое барменов за стойкой | полоса «Люди, которые работают в паре» |
| `kitchen-line.jpg` | Повар за работой на кухне | там же, второй кадр |

**Править код не нужно.** Как только файл с нужным именем появится в этой папке,
страница подхватит его сама и заглушка исчезнет.

Пропорции тоже подгонять не надо: рамки на странице имеют фиксированную форму, фото
обрезается по центру автоматически. Портреты встают в вертикальную арку 4:5, кадры в
полосе — в горизонтальную 4:3. Просто проверьте, что главное на снимке не у самого края.

## Как загрузить через сайт GitHub

1. Откройте репозиторий → папку `assets/img`.
2. Кнопка **Add file** → **Upload files**.
3. Перетащите файлы в окно.
4. Внизу нажмите **Commit changes**.

Через минуту сайт обновится. Если фото не появилось — скорее всего расширение `.JPG`
или `.jpeg` вместо `.jpg`: переименуйте и загрузите снова.

## Перед загрузкой сожмите файлы

Снимки с телефона весят 3–8 МБ, и страница из-за них будет открываться медленно.
Прогоните через [Squoosh](https://squoosh.app): ширина до 1600 px, формат JPEG,
качество 75–80. Должно получиться примерно 150–300 КБ на кадр.

## Остальные файлы в папке

- `og-cover.svg` — картинка, которая показывается при отправке ссылки в мессенджер.
  Готова, менять не нужно.
- `favicon.svg` — иконка вкладки в браузере. Тоже готова.
- `*.svg` с подписями — заглушки. Удалять их не надо: они страхуют страницу, если
  какое-то фото не загрузится.
