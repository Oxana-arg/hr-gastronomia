# HR para Gastronomía — лендинг Оксаны Юрченко

Подбор персонала и HR-консалтинг для гастроиндустрии Аргентины.
Русская и испанская версии, статический сайт без сборки и без зависимостей.

- Русская версия — `index.html`
- Испанская версия — `es/index.html`
- Какие нужны фотографии — [`assets/img/README.md`](assets/img/README.md)

---

## Как опубликовать

Репозиторий уже называется `hr-gastronomia` и открыт для всех — этого достаточно,
чтобы GitHub Pages работали бесплатно. Осталось их включить:

1. Репозиторий → **Settings** → в левом меню **Pages**.
2. В блоке *Build and deployment*, поле *Source*, выбрать **Deploy from a branch**.
3. Ниже выбрать ветку `claude/oxana-personal-landing-e7uvxk` и папку **`/ (root)`**.
   Нажать **Save**.
4. Через 1–2 минуты обновить страницу — вверху появится адрес
   `https://oxana-arg.github.io/hr-gastronomia/`.

Испанская версия открывается по тому же адресу с `/es/` на конце.

### Свой домен

Купите домен, добавьте в корень репозитория файл `CNAME` с одной строкой — вашим доменом
(например `hrparagastronomia.com`), а у регистратора пропишите записи, которые GitHub
покажет в Settings → Pages. После этого в `index.html`, `es/index.html`, `sitemap.xml`
и `robots.txt` нужно заменить `https://oxana-arg.github.io/hr-gastronomia/` на новый
адрес — это десяток строк, обычным поиском по файлу.

## Как менять тексты

Тексты лежат прямо в HTML — редактировать можно на самом GitHub, ничего не устанавливая:
откройте файл, нажмите карандаш, поправьте, нажмите **Commit changes**. Через минуту
правка появится на сайте.

Важно: **одну и ту же правку нужно внести в оба файла** — `index.html` (русский) и
`es/index.html` (испанский). Структура блоков в них одинаковая.

### Контакты

## Как поменять цвета

Палитра одна — пудрово-винная. Все цвета собраны в начале `assets/css/styles.css`,
в разделе «Палитра»: одна переменная — один цвет, меняется в одном месте и подхватывается
по всей странице.

```css
--accent: #9C4257;   /* акценты: надзаголовки, цены, росчерк */
--deep:   #6E2B3D;   /* фон основной кнопки */
--bg:     #FBF4F3;   /* фон страницы */
```

Два других варианта, песочно-шалфейный и лавандово-мятный, лежат в истории git
(коммит `ff6de48`) — если захотите вернуться, они не потеряны.

## Как посмотреть локально

Файлы нужно открывать через веб-сервер, а не двойным кликом — иначе браузер
заблокирует загрузку шрифтов.

```bash
python3 -m http.server 8000
```

Дальше открыть `http://localhost:8000` (русская версия) и `http://localhost:8000/es/`.

---

## Как поменять название

Название стоит в четырёх местах каждого файла: `<title>`, `og:title`, блок `brand`
в шапке и `footer__title` в подвале. Плюс в `assets/img/og-cover.svg` — это картинка,
которая показывается при отправке ссылки в мессенджер.

## Что внутри

```
index.html              русская версия
es/index.html           испанская версия
assets/css/styles.css   вся вёрстка, палитра, подключение шрифтов
assets/js/main.js       меню, появление блоков, год в подвале (~1,5 КБ)
assets/fonts/           Prata и Golos Text, лицензия SIL OFL 1.1
assets/img/             заглушки под фотографии, фавикон, обложка для мессенджеров
.nojekyll               чтобы GitHub Pages отдавал файлы как есть
robots.txt, sitemap.xml для поисковиков
```

Шрифты лежат в репозитории, а не подгружаются с Google Fonts: страница открывается
быстрее, работает без внешних запросов и не зависит от доступности чужого сервера.
Оба шрифта распространяются по SIL Open Font License 1.1 — тексты лицензий в
`assets/fonts/`.
